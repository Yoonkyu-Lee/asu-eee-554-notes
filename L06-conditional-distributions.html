00

이 모듈이 하는 일

What this module does

한 줄 요약: Module 3의 조건부 확률을 분포 전체에 적용한다.

In one line: Module 3's conditional probability, applied to a whole distribution.

Module 5에서 확률변수 X 하나의 분포를 FX(x) = P(X ≤ x)로 적는 법을 배웠어. Module 3에서는 사건 하나의 확률이 새 정보를 만나면 P(A | M)으로 갱신된다는 걸 배웠고. 이 모듈은 그 둘이 만나는 자리야. A 자리에 {X ≤ x}를 넣으면 무슨 일이 생기나?

Module 5 taught you to write the distribution of a single random variable as FX(x) = P(X ≤ x). Module 3 taught you that the probability of one event gets updated to P(A | M) when new information arrives. This module is where the two meet. What happens if you put {X ≤ x} in the A slot?

Module 3의 P(A|M) = P(A ∩ M) / P(M)가 여기서 일한다. 새 정의가 아니야. A = {X ≤ x}로 두고 x를 모든 실수에 대해 훑으면 함수 하나가 나와. 그게 조건부 CDF야.

그래서 이 모듈에는 새 공리가 없어. 슬라이드가 명시해. P(·|M)은 그 자체로 확률 측도니까, 그것으로 만든 FX|M는 자동으로 정상적인 CDF야. Module 5에서 배운 CDF의 성질이 전부 그대로 성립해.
Module 3's P(A|M) = P(A ∩ M) / P(M) is what does the work here. Nothing new is being defined. Put A = {X ≤ x}, sweep x over the reals, and you have a function. That function is the conditional CDF.

So this module introduces no new axiom. The slides say it outright: P(·|M) is itself a probability measure, so the FX|M built from it is automatically a legitimate CDF. Every property of CDFs from Module 5 carries over untouched.

Where the textbook differs

Hajek has no section matching this module. Search all of Chapter 1 and there is nothing on conditioning a random variable's distribution on an event. §1.2 covers conditional probability of events, §1.3 covers random variables and their distributions, and this module is the composition of the two, so the book never bothered to give it a section.

Do not be fooled by §1.9, "Conditional densities." The name is close but the content is not. That section is about fX|Y, conditioning on another random variable, and it needs joint distributions (§1.8) first. This module conditions on an event M. §1.9 picks up later, once several random variables are in play. Not yet.

01

정보가 분포를 바꾼다

Information reshapes a distribution

슬라이드는 이미 아는 것 두 개를 나란히 놓고 시작한다.

The slides open by putting two things you already know side by side.

슬라이드 2쪽이 복습 두 줄로 시작해. 하나는 Module 5, 하나는 Module 3이야.

Slide 2 opens with two lines of review, one from Module 5 and one from Module 3.

FX(x) = P(X ≤ x) 확률변수의 분포는 CDF로 기술된다 (Module 5)a random variable's distribution is described by its CDF (Module 5)
P(A | M) = P(A ∩ M) ⁄ P(M) 새 정보는 확률을 이렇게 바꾼다 (Module 3)new information changes probabilities like this (Module 3)

그러고 3쪽이 질문을 던져. "새 정보가 X의 분포를 어떻게 바꾸는가?" 사건 M이 일어났다는 걸 알게 되면 P(X ≤ x)가 P(X ≤ x | M)으로 갱신돼. 그런데 x는 하나가 아니야. 모든 실수 x에 대해 동시에 갱신되는 거고, 그 갱신된 값들을 모아놓은 게 새로운 분포야.

Slide 3 then asks the question: "How does new information change the distribution of X?" Once you learn that M occurred, P(X ≤ x) updates to P(X ≤ x | M). But there is not one x. Every real x updates at once, and collecting all those updated values gives you a new distribution.

이게 이 모듈 전체의 한 문장이야. 조건부 확률은 숫자 하나를 갱신하고, 조건부 분포는 함수 전체를 갱신해. 슬라이드 4쪽이 그 연결을 한 줄로 적어: A = {X ≤ x}로 두면 P(A|M) = P(X ≤ x | M)이고, 이게 다음 정의를 부른다.
That is the whole module in one sentence. Conditional probability updates one number; a conditional distribution updates an entire function. Slide 4 writes the bridge in a single line: set A = {X ≤ x} and P(A|M) = P(X ≤ x | M), which is what motivates the definition on the next slide.
02

조건부 CDF와 PDF

Conditional CDF and PDF

정의는 두 줄이면 끝난다. 나머지는 전부 이 두 줄의 결과다.

The definition takes two lines. Everything after this module is a consequence of them.

Definition 1 (슬라이드 5쪽)

사건 M이 주어졌을 때 X의 조건부 누적분포함수는

FX|M(x) = P(X ≤ x | M) = P({X ≤ x} ∩ M) ⁄ P(M)

X가 연속이면 조건부 확률밀도함수는 이걸 미분한 거야.

fX|M(x) = (d ⁄ dx) FX|M(x)
Definition 1 (slide 5)

The conditional cumulative distribution function of X given an event M is

FX|M(x) = P(X ≤ x | M) = P({X ≤ x} ∩ M) ⁄ P(M)

If X is continuous, the conditional probability density function is its derivative.

fX|M(x) = (d ⁄ dx) FX|M(x)
기호 뜯어보기 · 아래첨자의 세로 막대Unpacking the notation · the bar in the subscript

FX|M(x)는 기호가 네 조각이야. 조각마다 사는 세계가 달라서, 헷갈리면 식 전체가 안 읽혀.

F함수 이름. CDF라는 뜻.
X어떤 확률변수의 분포인지. 아래첨자 왼쪽.
|"주어졌을 때". 나눗셈 막대가 아니야. P(A|B)의 그 막대와 같은 것.
M조건이 되는 사건. 숫자가 아니라 Ω의 부분집합이다.
(x)함수의 입력. 이건 실수다.

레벨을 섞으면 안 되는 자리가 여기야. M은 아래첨자에 있고 x는 괄호 안에 있어. 둘 다 "조건" 같아 보이지만, M은 고정된 사건이고 x는 움직이는 변수야. M을 하나 정하면 함수 하나가 결정되고, 그 함수에 x를 넣는 거야.

FX|M를 통째로 읽으면 "M이 일어났다는 걸 아는 세계에서의 X의 CDF"가 돼. 슬라이드 6쪽이 강조하는 게 정확히 이거야. 다른 세계로 옮겨간 거지 새 종류의 물건이 생긴 게 아니야.

FX|M(x) is four pieces of notation, and each piece lives in a different world. Mix them up and the whole line stops parsing.

FThe name of the function. It says "CDF."
XWhose distribution this is. Left of the bar, in the subscript.
|"given." Not a division bar. It is the same bar as in P(A|B).
MThe conditioning event. A subset of Ω, not a number.
(x)The function's input. This one is a real number.

This is a place where levels get mixed up. M sits in the subscript and x sits in the parentheses. Both look like conditions, but M is a fixed event and x is a moving variable. Choose an M and you have pinned down one function; then you feed x to it.

Read FX|M as a whole and it says "the CDF of X in the world where you know M happened." That is exactly slide 6's point: you moved to a different world, you did not invent a new kind of object.

Module 2의 확률 측도 공리가 여기서 일한다. 슬라이드 6쪽이 근거를 한 줄로 대: P(·|M)은 그 자체로 확률 측도다. Module 3에서 P(·|M)이 Kolmogorov 공리 셋을 전부 만족한다는 걸 확인했잖아. 그러니까 FX|M를 만들 때 CDF의 성질(비감소, 0에서 1로, 우연속)을 다시 증명할 필요가 없어. 그냥 따라와.

이게 공리적으로 시작한 것의 배당금이야. Module 2에서 "왜 이렇게 까다롭게 시작하지"라고 느꼈던 게 여기서 증명 하나를 통째로 아껴줘.
Module 2's axioms for a probability measure are what is working here. Slide 6 gives the reason in one line: P(·|M) is itself a probability measure. In Module 3 you checked that P(·|M) satisfies all three Kolmogorov axioms. So when you build FX|M, the CDF properties (nondecreasing, 0 to 1, right continuous) do not need reproving. They come along for free.

This is the dividend of starting axiomatically. Whatever felt fussy about Module 2 just saved you an entire proof.
03

잘라내고 다시 채우기

Cut, then refill

첫 예제. M = {X ≤ a}. 이 하나로 조건부 분포의 감각이 잡힌다.

The first example, M = {X ≤ a}, is where the whole idea clicks.

슬라이드 7쪽이 정의를 그대로 쓰는 것부터 시작해.

Slide 7 starts by just writing out the definition.

FX|X≤a(x) = P({X ≤ x} ∩ {X ≤ a}) ⁄ P(X ≤ a)

분자의 교집합이 전부야. 두 사건 다 "X가 어떤 값 이하"라는 형태니까, 교집합은 더 빡빡한 쪽이 돼. 그래서 x와 a 중 누가 작냐로 경우가 갈려. 슬라이드 8쪽이 두 경우를 따로 적어.

The intersection in the numerator is the entire trick. Both events say "X is at most something," so their intersection is whichever constraint is tighter. Which means the case split is simply on whether x or a is smaller, and slide 8 writes out both.

경우case교집합the intersection결과result
x ≤ a {X ≤ x} ∩ {X ≤ a} = {X ≤ x} FX|M(x) = FX(x) ⁄ FX(a)
x > a {X ≤ x} ∩ {X ≤ a} = {X ≤ a} FX|M(x) = 1

두 번째 줄이 재밌어. x > a면 분자와 분모가 같은 사건이라 값이 정확히 1이야. 조건부 세계에서는 X가 a를 넘을 가능성이 아예 없어. 이미 안 넘었다는 걸 알고 있으니까.

The second row is the interesting one. When x > a the numerator and the denominator are the same event, so the value is exactly 1. In the conditioned world there is no chance at all that X exceeds a, because you already know it did not.

슬라이드 9쪽이 둘을 합치고 미분해.

Slide 9 merges the cases and differentiates.

슬라이드 9쪽
fX|X≤a(x) = fX(x) ⁄ FX(a)   (x ≤ a),    0   (x > a)

FX(a)는 x에 의존하지 않는 상수야. 그러니까 미분할 때 그냥 따라 나와. 모양은 그대로 두고 크기만 1 ⁄ FX(a)배 하는 거야.

Slide 9
fX|X≤a(x) = fX(x) ⁄ FX(a)   (x ≤ a),    0   (x > a)

FX(a) is a constant: it does not depend on x, so it simply rides through the derivative. The shape is untouched and only the scale changes, by a factor of 1 ⁄ FX(a).

슬라이드 10쪽이 이 그림을 한 문장으로 적어놨어. "X ≤ a로 조건부를 걸면 a 위의 밀도가 전부 제거되고, 남은 밀도는 적분이 1이 되도록 재정규화된다."

"모양 그대로"가 핵심이야. [0, a] 안에서 어떤 값이 다른 값보다 몇 배 그럴듯한지는 전혀 바뀌지 않아. 정보가 알려준 건 "a를 안 넘었다"뿐이고, 그 안에서 누가 더 유력한지는 아무 말도 안 했으니까.
Slide 10 states the picture in one sentence: "Conditioning on X ≤ a removes all probability density above a and renormalizes the remaining density so that its integral is one."

"Shape unchanged" is the part that matters. Inside [0, a], how much more plausible one value is than another does not move at all. The information told you only that a was not exceeded; it said nothing about who is favoured within that range.
예제 3.1 · 위쪽 꼬리로 조건부

슬라이드는 M = {X ≤ a}만 다뤄. 그런데 HW3 P3(f)와 Module 8의 대기시간 예제는 반대쪽, M = {X > a}를 물어. 슬라이드 7~9쪽을 그대로 따라가서 직접 만들어봐.

X가 연속이고 P(X > a) > 0일 때 FX|X>a(x)와 fX|X>a(x)를 구해.

풀이 보기

같은 자리에서 시작해. FX|M(x) = P({X ≤ x} ∩ {X > a}) ⁄ P(X > a).

분모는 P(X > a) = 1 − FX(a)야. 분자의 교집합은 이번에는 양쪽에서 잘린 구간이라 경우가 갈려.

  • x ≤ a: {X ≤ x} ∩ {X > a} = ∅이므로 값은 0.
  • x > a: 교집합은 {a < X ≤ x}이고 그 확률은 FX(x) − FX(a).
FX|X>a(x) = (FX(x) − FX(a)) ⁄ (1 − FX(a)),   x > a

미분하면 분자의 FX(a)는 상수라 사라지고, 분모는 상수라 그대로 남아.

fX|X>a(x) = fX(x) ⁄ (1 − FX(a)),   x > a,   그 외 0

구조가 똑같아. 살아남은 쪽의 확률로 나눌 뿐이야. 슬라이드 버전은 그 확률이 FX(a)고, 이쪽은 1 − FX(a)인 거지. 이 식이 Module 8의 무기억성 유도에 그대로 들어가.

Example 3.1 · conditioning on the upper tail

The slides only do M = {X ≤ a}. But HW3 P3(f) and the waiting-time example in Module 8 both want the other side, M = {X > a}. Rebuild it yourself by following slides 7 through 9.

For continuous X with P(X > a) > 0, find FX|X>a(x) and fX|X>a(x).

show the solution

Start in the same place: FX|M(x) = P({X ≤ x} ∩ {X > a}) ⁄ P(X > a).

The denominator is P(X > a) = 1 − FX(a). This time the intersection is an interval cut from both sides, so the cases go differently.

  • x ≤ a: {X ≤ x} ∩ {X > a} = ∅, so the value is 0.
  • x > a: the intersection is {a < X ≤ x}, with probability FX(x) − FX(a).
FX|X>a(x) = (FX(x) − FX(a)) ⁄ (1 − FX(a)),   x > a

Differentiate: FX(a) in the numerator is a constant and dies, the denominator is a constant and survives.

fX|X>a(x) = fX(x) ⁄ (1 − FX(a)),   x > a,   zero otherwise

Same structure. You divide by the probability of whatever survived. On the slides that was FX(a); here it is 1 − FX(a). This exact formula walks straight into the memorylessness derivation in Module 8.

함정

조건부 PDF가 1을 넘어도 괜찮다

위 그림의 오른쪽 봉우리가 1.0이야. Module 5에서 이미 짚었지만 여기서 다시 터져. PDF는 확률이 아니라 밀도라서 1을 넘을 수 있고, 조건부 PDF는 거의 항상 원래보다 커져. 재정규화가 나누기 FX(a) ≤ 1이니까.

극단적으로 a를 아주 작게 잡으면 FX(a)가 0에 가까워지고 조건부 밀도가 하늘로 치솟아. 그래도 면적은 언제나 정확히 1이야. 폭이 같이 좁아지니까.

잘라낸 쪽을 "작게" 만드는 게 아니다

x > a에서 fX|M(x)는 작은 값이 아니라 정확히 0이야. 시험에서 "거의 안 일어난다"로 두고 넘어가면 안 돼. 조건부 세계에서는 그 사건이 불가능해.

분모가 0이면 정의되지 않는다

P(M) = 0이면 이 정의는 아무 말도 못 해. Module 3의 조건부 확률과 똑같은 제약이야. 07번에서 이 제약을 정면으로 만나게 돼. 연속 확률변수에서 M = {X = x}는 확률이 0이거든.

Traps

A conditional PDF above 1 is fine

The peak on the right of the figure is 1.0. Module 5 already made this point, but it bites again here. A PDF is a density, not a probability, so it may exceed 1, and a conditional PDF is almost always larger than the original, since renormalizing divides by FX(a) ≤ 1.

Push a very small and FX(a) approaches zero while the conditional density shoots up. The area is still exactly 1, because the support narrows at the same rate.

The discarded side is not "made small"

For x > a, fX|M(x) is not a small number; it is exactly zero. Writing "basically never happens" on an exam misses the point. In the conditioned world that event is impossible.

A zero denominator leaves it undefined

If P(M) = 0 this definition says nothing at all. It is the same restriction as Module 3's conditional probability. Section 07 walks straight into it, because for a continuous random variable M = {X = x} has probability zero.

창으로 자르기

Cutting to a window

한쪽만 자르는 게 아니라 양쪽을 자르면 경우가 셋이 된다.

Cut on both sides instead of one and the case split goes from two to three.

슬라이드 11쪽이 M = {a1 < X ≤ a2}를 다뤄. 방법은 03번과 한 글자도 다르지 않아. 정의를 쓰고, 교집합을 정리하고, P(M)으로 나눠.

Slide 11 takes M = {a1 < X ≤ a2}. The method is character for character the same as §03: write the definition, simplify the intersection, divide by P(M).

슬라이드 11~12쪽
FX|M(x) = 0  (x ≤ a1)
FX|M(x) = (FX(x) − FX(a1)) ⁄ (FX(a2) − FX(a1))  (a1 < x ≤ a2)
FX|M(x) = 1  (x > a2)

미분하면 상수인 FX(a1)이 사라지고 분모만 남아.

fX|M(x) = fX(x) ⁄ (FX(a2) − FX(a1))  (a1 < x ≤ a2),   0  (그 외)
Slides 11 and 12
FX|M(x) = 0  (x ≤ a1)
FX|M(x) = (FX(x) − FX(a1)) ⁄ (FX(a2) − FX(a1))  (a1 < x ≤ a2)
FX|M(x) = 1  (x > a2)

Differentiating kills the constant FX(a1) and leaves the denominator standing.

fX|M(x) = fX(x) ⁄ (FX(a2) − FX(a1))  (a1 < x ≤ a2),   0  (otherwise)
03번과 04번은 사실 같은 공식이야. 창의 한쪽 끝을 무한으로 보내면 나머지가 떨어져 나와.

a1 → −∞로 두면 FX(a1) → 0이라 분모가 FX(a2)가 되고, 이건 03번의 {X ≤ a}야.
a2 → +∞로 두면 FX(a2) → 1이라 분모가 1 − FX(a1)가 되고, 이건 예제 3.1의 {X > a}야.

그러니까 공식 셋을 외우지 말고 하나만 기억해. 살아남은 구간의 밀도를, 그 구간의 확률로 나눈다. 나머지는 P(M)을 그때그때 계산하는 일이야.
§03 and §04 are really the same formula. Send one end of the window to infinity and the other cases fall out.

Let a1 → −∞: then FX(a1) → 0, the denominator becomes FX(a2), and you are back to §03's {X ≤ a}.
Let a2 → +∞: then FX(a2) → 1, the denominator becomes 1 − FX(a1), and you are back to Example 3.1's {X > a}.

So do not memorise three formulas. Remember one: take the density on whatever survived and divide by the probability of what survived. The rest is computing P(M) in each situation.
함정

조건부 CDF는 창 안에서 0에서 1까지 다 쓴다

원래 CDF는 a1에서 a2까지 가면서 F(a1)부터 F(a2)까지만 움직여. 창이 좁으면 조금만 움직이지. 그런데 조건부 CDF는 같은 구간에서 0에서 1까지 전부 훑어. 분모가 그만큼 작아서야.

HW3 P3(f)에서 답을 검산할 때 이걸 써. FX|M가 창의 왼쪽 끝에서 0, 오른쪽 끝에서 1이 아니면 틀린 거야.

부등호의 등호가 어디 붙는지

슬라이드는 {a1 < X ≤ a2}로 왼쪽은 열고 오른쪽은 닫아. CDF가 P(X ≤ x)라서 차를 뺄 때 딱 맞아떨어지게 하려는 거야. 연속 확률변수면 어차피 P(X = a) = 0이라 아무 차이가 없어. 그런데 이산이면 차이가 나. a1에 질량이 있으면 포함하냐 마냐로 답이 갈려. 05번에서 이 구분이 실제로 문제가 돼.

Traps

The conditional CDF uses the full range 0 to 1 inside the window

Going from a1 to a2, the original CDF only moves from F(a1) to F(a2), which is barely anything for a narrow window. The conditional CDF sweeps the whole way from 0 to 1 over that same interval, precisely because the denominator is that small.

Use this to check your answer in HW3 P3(f): if FX|M is not 0 at the left end of the window and 1 at the right end, something is wrong.

Where the equals sign sits

The slides write {a1 < X ≤ a2}, open on the left and closed on the right. That is so the difference of CDFs, each of which is P(X ≤ x), lands exactly right. For a continuous random variable it makes no difference at all, since P(X = a) = 0. For a discrete one it does. If there is mass sitting at a1, including it or not changes the answer. Section 05 is where that actually bites.

Beyond the slides

The pX|M used here is standard, but the course may pick a different symbol.

정의 (교재 기준)

사건 M이 주어졌을 때 이산 확률변수 X의 조건부 확률질량함수는

pX|M(k) = P(X = k | M) = P({X = k} ∩ M) ⁄ P(M)

M이 X의 값으로 표현되는 사건이면, 즉 M = {X ∈ S} 꼴이면 더 간단해져.

pX|M(k) = pX(k) ⁄ P(M)  (k ∈ S),    0  (k ∉ S)    P(M) = ∑j ∈ S pX(j)
Definition (from the textbook)

The conditional probability mass function of a discrete X given an event M is

pX|M(k) = P(X = k | M) = P({X = k} ∩ M) ⁄ P(M)

When M is itself phrased in terms of X, that is M = {X ∈ S}, it collapses further.

pX|M(k) = pX(k) ⁄ P(M)  (k ∈ S),    0  (k ∉ S)    P(M) = ∑j ∈ S pX(j)
예제 5.1 · 홀수라는 것만 알았을 때

X의 PMF가 pX(k) = c(1/3)k, k = 1, 2, 3이고 그 외에는 0이야.

(a) c를 구해. (b) X가 홀수라는 걸 알았을 때의 조건부 PMF를 구해. (c) X > 1이라는 걸 알았을 때의 조건부 PMF를 구해.

풀이 보기

(a) 전부 더해서 1이 되게 해. 1/3 + 1/9 + 1/27 = 13/27이니까 c = 27/13. 그러면

pX(1) = 9/13,   pX(2) = 3/13,   pX(3) = 1/13

(b) M = {X ∈ {1, 3}}이고 P(M) = 9/13 + 1/13 = 10/13.

pX|M(1) = (9/13) ⁄ (10/13) = 9/10,    pX|M(3) = 1/10,    pX|M(2) = 0

검산 두 가지. 합이 1이야. 그리고 9/10 : 1/10 = 9 : 1인데 원래도 9/13 : 1/13 = 9 : 1이었어. 비율이 보존됐으면 제대로 한 거야.

(c) M′ = {X ∈ {2, 3}}이고 P(M′) = 3/13 + 1/13 = 4/13.

pX|M′(2) = 3/4,    pX|M′(3) = 1/4,    pX|M′(1) = 0

HW3 P1은 밑이 1/2이고 k가 4까지야. 숫자가 다르니 직접 해봐. 절차는 이것과 똑같아. (d)는 (c) 유형, (e)는 (b) 유형이고, (f)는 방금 확인한 "비율은 보존되는데 값은 커진다"를 말로 설명하는 문제야.

Example 5.1 · all you learn is that it is odd

X has PMF pX(k) = c(1/3)k for k = 1, 2, 3 and zero elsewhere.

(a) Find c. (b) Find the conditional PMF given that X is odd. (c) Find the conditional PMF given X > 1.

show the solution

(a) Make it sum to one. 1/3 + 1/9 + 1/27 = 13/27, so c = 27/13 and

pX(1) = 9/13,   pX(2) = 3/13,   pX(3) = 1/13

(b) M = {X ∈ {1, 3}} with P(M) = 9/13 + 1/13 = 10/13.

pX|M(1) = (9/13) ⁄ (10/13) = 9/10,    pX|M(3) = 1/10,    pX|M(2) = 0

Two checks. It sums to one. And 9/10 : 1/10 = 9 : 1, which is what 9/13 : 1/13 was to begin with. If the ratio survived, you did it right.

(c) M′ = {X ∈ {2, 3}} with P(M′) = 3/13 + 1/13 = 4/13.

pX|M′(2) = 3/4,    pX|M′(3) = 1/4,    pX|M′(1) = 0

HW3 P1 uses base 1/2 and runs k up to 4, so the numbers are different. Do it yourself. The procedure is identical: (d) is the shape of part (c), (e) is the shape of part (b), and (f) asks you to say in words the thing you just verified, that the ratios hold while the values grow.

예제 5.2 · geometric을 조건부 지으면

패킷을 성공할 때까지 독립적으로 재전송하고, 매 시도의 성공 확률은 p = 0.4야. X를 첫 성공까지의 시도 횟수라고 하면 pX(k) = (1 − p)k−1p, k ≥ 1.

세 번을 시도했는데 아직 성공하지 못했어. 즉 M = {X > 3}. 조건부 PMF pX|M(k)를 구하고, 모양을 관찰해.

풀이 보기

먼저 분모. X > 3이란 건 처음 세 번이 전부 실패했다는 뜻이야.

P(X > 3) = (1 − p)3 = 0.63 = 0.216

분자는 k > 3에서 원래 PMF 그대로야.

pX|M(k) = (1 − p)k−1p ⁄ (1 − p)3 = (1 − p)k−4p,   k ≥ 4

여기를 봐. j = k − 3으로 바꾸면 pX|M(j + 3) = (1 − p)j−1p가 돼. 이건 원래 PMF와 똑같은 식이야. 시작점만 3칸 옮겨졌어.

말로 옮기면 이래. 세 번 실패했다는 사실은 앞으로 몇 번을 더 해야 하는지에 대해 아무 정보도 주지 않는다. 처음부터 다시 시작하는 것과 구분이 안 돼. 이게 기하분포의 무기억성(memoryless property)이야. Hajek 교재 §1.6이 이걸 P(X > i + j | X > i) = P(X > j)로 적어.

HW3 P2는 p = 0.25이고 조건이 X > 10이야. 숫자가 다르니 직접 해봐. P2(e)의 P(X > 10 | X > 4)도 같은 성질의 다른 얼굴이고, 연속판인 지수분포의 무기억성은 Module 8 §07에서 나와.

Example 5.2 · conditioning a geometric

A packet is retransmitted independently until it succeeds, each attempt succeeding with probability p = 0.4. Let X be the number of attempts up to and including the first success, so pX(k) = (1 − p)k−1p for k ≥ 1.

Three attempts have gone by with no success, so M = {X > 3}. Find pX|M(k) and look at its shape.

show the solution

The denominator first. X > 3 means the first three attempts all failed.

P(X > 3) = (1 − p)3 = 0.63 = 0.216

The numerator is the original PMF, untouched, for k > 3.

pX|M(k) = (1 − p)k−1p ⁄ (1 − p)3 = (1 − p)k−4p,   k ≥ 4

Now look at it. Substituting j = k − 3 gives pX|M(j + 3) = (1 − p)j−1p, which is the original PMF, character for character, with the starting point shifted by three.

In words: knowing that three attempts failed tells you nothing about how many more you need. It is indistinguishable from starting over. That is the memoryless property of the geometric distribution, which Hajek §1.6 writes as P(X > i + j | X > i) = P(X > j).

HW3 P2 uses p = 0.25 and conditions on X > 10, so the numbers are different. Do it yourself. P2(e)'s P(X > 10 | X > 4) is the same property wearing a different face, and the continuous version, memorylessness of the exponential, shows up in Module 8 §07.

전확률 법칙, 분포 버전

Total probability for distributions

Module 3에서 숫자에 대해 했던 걸, 이번엔 함수에 대해 한다.

What Module 3 did for numbers, done here for functions.

Module 3의 전확률 법칙 기억하지. 분할 {A1, …, An}이 있으면 P(B) = ∑ P(B|Ai)P(Ai)였어. 슬라이드 13쪽이 B 자리에 {X ≤ x}를 넣어.

You know Module 3's law of total probability: given a partition {A1, …, An}, P(B) = ∑ P(B|Ai)P(Ai). Slide 13 puts {X ≤ x} in the B slot.

슬라이드 13쪽

{A1, …, An}이 Ω의 분할이면

FX(x) = ∑i=1n FX|Ai(x) P(Ai)

X가 연속이면 양변을 미분해서

fX(x) = ∑i=1n fX|Ai(x) P(Ai)
Slide 13

If {A1, …, An} is a partition of Ω, then

FX(x) = ∑i=1n FX|Ai(x) P(Ai)

and if X is continuous, differentiate both sides:

fX(x) = ∑i=1n fX|Ai(x) P(Ai)
기호 뜯어보기 · 함수를 더한다는 것Unpacking the notation · adding functions

이 합에는 지금까지와 다른 점이 하나 있어. 더해지는 게 숫자가 아니라 함수야.

∑i=1n골격은 늘 보던 것과 같다. i를 1부터 n까지 돌린다.
fX|Ai(x)Ai가 일어났다는 가정 아래의 밀도. 조각마다 다른 함수.
P(Ai)그 조각의 무게. x와 무관한 숫자. 다 더하면 1.

펼쳐 쓰면 이렇게 돼. x가 고정된 하나의 값이라고 보면 그냥 가중 평균이야.

fX(x) = fX|A1(x)P(A1) + fX|A2(x)P(A2) + ⋯

그런데 x가 고정이 아니야. 모든 x에서 동시에 성립하는 식이라 결과가 함수 하나가 돼. 이런 걸 혼합(mixture)이라고 불러. 가중치가 다 양수고 합이 1이니까, 조각들이 전부 정상적인 밀도면 섞은 것도 정상적인 밀도야.

This sum differs from the ones you have seen in one way: the things being added are functions, not numbers.

∑i=1nSame skeleton as always: run i from 1 to n.
fX|Ai(x)The density assuming Ai happened. A different function for each piece.
P(Ai)That piece's weight. A number, independent of x. They sum to one.

Written out, and reading x as one fixed value, it is an ordinary weighted average.

fX(x) = fX|A1(x)P(A1) + fX|A2(x)P(A2) + ⋯

Except x is not fixed. The identity holds at every x at once, so the result is a whole function. This construction is called a mixture. Since the weights are nonnegative and sum to one, mixing valid densities gives a valid density.

함정

P(Ai)를 곱하는 걸 빼먹는다

조건부 밀도들을 그냥 더하면 적분이 n이 돼. 각각이 이미 1로 정규화돼 있으니까. 가중치가 있어야 합이 1로 돌아와. 위 그림에서 0.6 + 0.4 = 1이 그 역할이야.

분할이 아니면 성립하지 않는다

Ai들이 서로 배타적이고 전체를 덮어야 해. 겹치면 그 구간을 두 번 세고, 덮지 못하면 확률이 새어나가. Module 3에서 짚었던 것과 똑같은 조건이야. 그래서 실전에서는 A와 Ac 두 조각으로 쓰는 경우가 압도적으로 많아. 그러면 조건을 확인할 필요가 없거든.

이산과 연속이 섞이면

CDF 버전은 X가 이산이든 연속이든 성립해. 그런데 PDF 버전은 모든 조각이 연속일 때만 말이 돼. 조각 하나가 이산이면 그 조각에는 밀도가 없으니까 미분하는 순간 깨져. 슬라이드가 "X가 연속이면"이라는 단서를 괜히 붙인 게 아니야.

Traps

Forgetting to multiply by P(Ai)

Adding the conditional densities straight up gives something that integrates to n, since each one already normalises to 1. The weights are what bring the total back to one. In the figure that is the job of 0.6 + 0.4 = 1.

It fails if the pieces are not a partition

The Ai must be mutually exclusive and cover everything. Overlap and you count a region twice; leave a gap and probability leaks out. Same condition as in Module 3. Which is why in practice people overwhelmingly use the two-piece version, A and Ac: then there is nothing to check.

When the pieces are not all continuous

The CDF version holds whether X is discrete or continuous. The PDF version needs every piece to be continuous. If one piece is discrete it has no density, and differentiating breaks. The slides attach the qualifier "if X is continuous" for a reason.

확률 0인 사건으로?

Conditioning on probability zero

연속이면 P(X = x) = 0이다. 그런데도 P(Ai | X = x)를 쓰고 싶다.

For continuous X, P(X = x) = 0. And yet we want to write P(Ai | X = x).

슬라이드 14쪽이 문제를 정면으로 꺼내. 지금까지의 모든 식은 P(M) > 0을 전제했어. 그런데 실제 공학 상황은 정반대야. 수신기가 관측하는 건 "신호가 0.2다"라는 정확한 값이지 "0.1과 0.3 사이다"가 아니거든. 그리고 연속 확률변수에서 그 사건의 확률은 정확히 0이야.

Slide 14 puts the problem on the table. Every formula so far assumed P(M) > 0. Real engineering situations are the opposite. A receiver observes "the signal is 0.2", an exact value, not "between 0.1 and 0.3". And for a continuous random variable that event has probability exactly zero.

Module 5의 "연속이면 점 하나의 확률은 0"이 여기서 청구서로 돌아온다. 그때는 P(X = 1) = 0인데도 X = 1이 불가능한 건 아니라는 이야기였어. 이제 그 사건으로 조건부를 걸어야 하는데, P(A|M) = P(A ∩ M)/P(M)은 0/0이 돼버려.

슬라이드의 해법은 정의를 고치는 게 아니라 극한으로 접근하는 거야. 점 대신 Δ-폭 구간을 쓰고, 계산이 끝난 뒤에 Δ → 0으로 보내.
Module 5's "a single point has probability zero" comes back as a bill here. Back then the point was that P(X = 1) = 0 does not make X = 1 impossible. Now you have to condition on such an event, and P(A|M) = P(A ∩ M)/P(M) turns into 0/0.

The slides do not patch the definition. They approach it by a limit. Use a window of width Δ instead of a point, do the algebra, then send Δ → 0.
슬라이드 14~15쪽 · 세 걸음

1. 점을 구간으로 바꾼다. P(Ai | X = x) 대신 P(Ai | x − Δ/2 < X ≤ x + Δ/2)를 본다. 이건 확률이 양수라 Module 3의 Bayes를 그대로 쓸 수 있다.

P(Ai | Δ구간) = P(Δ구간 | Ai) P(Ai) ⁄ P(Δ구간)

2. 작은 Δ에서 구간 확률을 밀도로 근사한다. 이게 밀도의 정의 그 자체다.

P(Δ구간) ≈ fX(x) Δ,    P(Δ구간 | Ai) ≈ fX|Ai(x) Δ

3. Δ가 약분된다. 분자와 분모에 똑같이 하나씩 있으니까.

P(Ai | Δ구간) ≈ fX|Ai(x) P(Ai) ⁄ fX(x)
Slides 14 and 15 · three steps

1. Replace the point with a window. Instead of P(Ai | X = x), look at P(Ai | x − Δ/2 < X ≤ x + Δ/2). This has positive probability, so Module 3's Bayes applies as written.

P(Ai | window) = P(window | Ai) P(Ai) ⁄ P(window)

2. For small Δ, approximate each window probability by a density. This is the definition of a density, nothing more.

P(window) ≈ fX(x) Δ,    P(window | Ai) ≈ fX|Ai(x) Δ

3. The Δ cancels, since there is exactly one in the numerator and one in the denominator.

P(Ai | window) ≈ fX|Ai(x) P(Ai) ⁄ fX(x)
함정

fX(x)Δ는 근사값이지 확률이 아니다

슬라이드가 ≈를 쓰는 건 이유가 있어. 구간 안에서 밀도가 변하니까 정확한 값은 ∫야. Δ가 작을수록 근사가 좋아지고, 극한에서 정확해져. 식을 쓸 때 =로 쓰면 안 돼.

밀도의 비율이지 확률의 비율이 아니다

결과 식의 fX|Ai(x)는 확률이 아니야. 1보다 클 수도 있어. 그런데 P(Ai | X = x)는 진짜 확률이라 반드시 [0,1] 안에 있어야 해. 이게 모순처럼 보이면, 분모의 fX(x)가 분자를 포함한 합이라는 걸 기억해. 분자는 언제나 분모 이하야.

이 근사는 밀도가 x에서 연속일 때만 쓴다

밀도가 x에서 점프하면 P(구간) ≈ f(x)Δ가 무너져. 좌극한과 우극한 중 뭘 써야 할지가 정해지지 않으니까. 시험 문제의 밀도는 대개 구간별로 연속이라 문제가 안 되는데, 경계점에서는 조심해야 해. HW3 P5의 밀도들도 x = 0과 x = 1에서 끊겨.

Traps

fX(x)Δ is an approximation, not a probability

The slides write ≈ deliberately. The density varies across the window, so the exact value is an ∫. Smaller Δ means a better approximation, exact in the limit. Do not write it with an =.

It is a ratio of densities, not of probabilities

The fX|Ai(x) in the answer is not a probability and may exceed 1. Yet P(Ai | X = x) is a genuine probability and must land in [0,1]. If that feels contradictory, remember that the denominator fX(x) is a sum that contains the numerator. The numerator can never exceed it.

The approximation needs the density to be continuous at x

If the density jumps at x, then P(window) ≈ f(x)Δ falls apart: there is no telling whether to use the left or the right limit. Exam densities are usually piecewise continuous so it rarely matters, but be careful at the boundaries. The densities in HW3 P5 are discontinuous at x = 0 and x = 1.

Bayes with a continuous observation

확률 0인 값을 관측해도 정보는 얻는다. 이 모듈의 결론이다.

Observing a value of probability zero still tells you something. That is the module's punchline.

Bayes' Rule (슬라이드 16쪽)

X가 연속이고 {Ai}가 Ω의 분할일 때

P(Ai | X = x) = fX|Ai(x) P(Ai) ⁄ fX(x)

분모의 fX(x)는 06번의 전확률 법칙으로 채워: fX(x) = ∑j fX|Aj(x) P(Aj). 06번과 08번은 한 세트야. 06번이 분모를 만들고 08번이 그걸 쓴다.

Bayes' Rule (slide 16)

For continuous X and a partition {Ai} of Ω,

P(Ai | X = x) = fX|Ai(x) P(Ai) ⁄ fX(x)

Fill in the denominator with §06's law of total probability: fX(x) = ∑j fX|Aj(x) P(Aj). Sections 06 and 08 are one unit: §06 builds the denominator, §08 spends it.

슬라이드 16쪽이 붙이는 문장이 이 모듈의 결론이야. "X = x가 확률 0인 사건이라도, 연속값 x를 관측하는 것은 어느 Ai가 일어났는지에 대한 정보를 준다. 조건부 확률은 x 주변 밀도의 국소적 거동을 통해 정의된다."

The sentence slide 16 attaches is the module's conclusion: "Although the event X = x has probability zero, observing a continuous value x can still provide information about which event Ai occurred. The conditional probability is defined through the local behavior of the probability densities around x."

Example 8.1 · do it by hand

The same setup as the tool above: P(A1) = 0.6, P(A2) = 0.4, fX|A1(x) = 1, fX|A2(x) = 2x, both on 0 ≤ x ≤ 1.

(a) Find fX(x). (b) Write P(A1 | X = x) as a function of x. (c) Evaluate it at x = 0.25 and x = 0.75. (d) Say in words why the posterior for A1 falls as x grows.

show the solution

(a) Total probability, from §06.

fX(x) = 1 · 0.6 + 2x · 0.4 = 0.6 + 0.8x,   0 ≤ x ≤ 1

Check it first. ∫01(0.6 + 0.8x) dx = 0.6 + 0.4 = 1. Good.

(b) Bayes, unmodified.

P(A1 | X = x) = 1 · 0.6 ⁄ (0.6 + 0.8x) = 0.6 ⁄ (0.6 + 0.8x)

(c) At x = 0.25 the denominator is 0.6 + 0.2 = 0.8, giving 0.6/0.8 = 0.75. At x = 0.75 it is 0.6 + 0.6 = 1.2, giving 0.6/1.2 = 0.5.

(d) The bad channel's density 2x grows with x while the good channel's stays flat at 1. So a large reading is an observation the bad channel explains better. The prior leans toward the good channel, but the evidence pushes the other way. At x = 0.75 the two exactly balance, and above that the bad channel wins.

HW3 P5 uses priors 0.7 / 0.3 and a bad-channel density of 2(1 − x). Different numbers and, more to the point, the opposite direction: there the posterior leans toward the good channel as x grows. Same procedure, so do it yourself, and when you answer part (f) it is worth comparing against this example.

함정

likelihood를 확률로 읽는다

fX|A2(0.9) = 1.8이야. 1보다 커. 이건 확률이 아니라 밀도고, 여기서는 "A2가 A1보다 이 관측을 1.8배 잘 설명한다"는 상대적인 뜻으로만 쓰여. Bayes 식이 분모로 나눠주니까 최종 결과는 반드시 [0,1]에 들어와.

사전확률을 빼먹고 likelihood만 비교한다

likelihood가 큰 쪽이 항상 이기는 게 아니야. 위 도구에서 P(A1)을 0.9로 올려봐. x = 0.9에서 likelihood는 1 대 1.8로 A2가 이기는데, 사후확률은 여전히 A1이 이겨. 증거와 사전믿음이 곱해지는 구조라 그래.

사후확률이 사전확률과 같아지는 경우

두 likelihood가 같으면, 즉 fX|A1(x) = fX|A2(x)이면 사후확률이 사전확률과 정확히 같아. 위 설정에서는 2x = 1, 즉 x = 0.5가 그 점이야. 그 관측은 아무 정보도 주지 않았다는 뜻이고, 이게 Module 4의 독립과 이어져. 관측이 정보를 안 주면 믿음이 안 움직여.

Traps

Reading a likelihood as a probability

fX|A2(0.9) = 1.8, which is larger than one. It is a density, not a probability, and here it carries only a relative meaning: "A2 explains this observation 1.8 times as well as A1 does." Bayes divides by the marginal, so the final answer always lands in [0,1].

Comparing likelihoods and forgetting the prior

The larger likelihood does not automatically win. Push P(A1) to 0.9 in the tool above. At x = 0.9 the likelihoods are 1 against 1.8, favouring A2, yet A1 still holds the larger posterior. Evidence and prior belief multiply; neither one decides alone.

When the posterior equals the prior

If the two likelihoods agree, that is fX|A1(x) = fX|A2(x), the posterior is exactly the prior. In the setup above that happens where 2x = 1, at x = 0.5. It means the observation carried no information, which is exactly Module 4's independence showing up again: no information, no movement in belief.

Next comes transforming a random variable. This module reshaped a distribution using information: cut, then refill. The next module reshapes one using a deterministic function, finding the distribution of Y = g(X).

Put them side by side and the symmetry shows. Conditioning shrinks the support and scales the surviving density by a constant. Transforming moves the support and stretches or compresses the density by |dx/dy|. Both fall out of one constraint: the area has to stay at 1.

And Module 8 will spend both. E[g(X)] needs Module 7; E[X|M] needs this one.
