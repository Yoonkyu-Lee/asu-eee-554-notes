00

이 모듈이 하는 일

What this module does

한 줄 요약: 사건에 붙이던 확률을 숫자에 붙인다.

In one line: probability moves from events onto numbers.

Module 1부터 4까지는 확률을 사건(집합)에 붙였어. P({SS, SF})처럼. 그런데 공학에서 실제로 궁금한 건 결과 자체가 아니라 그 결과에 딸린 숫자야. 수신 전력이 몇 W인지, 패킷이 몇 ms 지연됐는지, 큐에 몇 개가 쌓였는지.

Modules 1 through 4 attached probability to events, which are sets, as in P({SS, SF}). But in engineering the thing you actually want is rarely the outcome itself; it is a number that comes with the outcome. How many watts arrived, how many milliseconds the packet took, how many jobs are in the queue.

이 전환이 왜 결정적이냐면, 숫자에는 순서와 연산이 있기 때문이야. 사건에는 "더한다", "평균낸다", "이것보다 크다"가 없어. {SS, SF}의 평균이란 게 없잖아. 그런데 숫자로 옮기면 P(X ≤ x), 기댓값, 분산이 전부 말이 돼.

그래서 이 모듈 이후로 과목의 성격이 바뀐다. 지금까지는 집합을 세는 일이었고, 앞으로는 함수와 적분을 다루는 일이야. 교재도 여기서 §1.3부터 두꺼워져.
The move matters because numbers come with order and arithmetic. Events have no notion of adding, averaging, or being greater than something; there is no such thing as the average of {SS, SF}. Push everything onto numbers and P(X ≤ x), expectation, and variance all start to mean something.

The character of the course changes from here on. Up to now the work was counting sets; from now on it is functions and integrals. The textbook thickens at the same point, from §1.3 onward.

The thing to keep straight is how CDF, PMF and PDF relate. All three describe a distribution, but they do not apply equally: the CDF always exists, the PMF only for discrete variables, the PDF only for continuous ones. The slides put that in bold for a reason.

01

왜 확률변수인가

Why random variables

확률 공간은 완전하지만 다루기 불편하다.

The probability space is complete but awkward to work with.

슬라이드가 먼저 인정하고 시작해. (Ω, ℱ, P)는 실험의 무작위성을 완전히 기술해. 부족한 게 없어. 그런데 "공학에서 우리는 결과 자체에는 거의 관심이 없다"고 이어져.

The slides open by conceding the point. (Ω, ℱ, P) describes the randomness of an experiment completely; nothing is missing. And then: "in engineering we are rarely interested in the outcomes themselves."

무선 채널 예제가 이걸 잘 보여줘. 결과 ω 하나는 "잡음이 이렇게 실현되고, 페이딩이 저렇게 실현되고, 간섭이 그렇게 실현된 상황" 전체야. 이걸 직접 다루는 건 거의 불가능해.

그런데 궁금한 건 대개 하나야. X(ω) = 수신 전력, Y(ω) = SNR, Z(ω) = 패킷 지연. 슬라이드 표현대로 P(X > ε)를 구하는 게 ω를 직접 다루는 것보다 훨씬 쉬워.
The wireless example makes this concrete. A single outcome ω is an entire situation: this particular noise realization, that particular fade, that particular interference pattern. Working with it directly is close to hopeless.

What you want is almost always one number: X(ω) the received power, Y(ω) the SNR, Z(ω) the packet delay. As the slides put it, computing P(X > ε) can be far easier than reasoning about ω itself.
02

정의: Ω에서 ℝ로

Definition: from Ω to ℝ

확률변수는 변수가 아니라 함수다.

A random variable is not a variable. It is a function.

정의

확률변수는 모든 결과에 숫자 하나를 대응시키는 함수야.

X : Ω → ℝ,    ω ↦ X(ω)

표기 관습. 슬라이드가 명시해. 보통 ω 의존성을 생략하고 그냥 X라고 써. ω가 있다는 건 암묵적으로 이해하는 거야.

Definition

A random variable is a function assigning one number to every outcome.

X : Ω → ℝ,    ω ↦ X(ω)

A notational convention, stated on the slides: the dependence on ω is normally suppressed and one just writes X, with ω understood.

기호 뜯어보기 · 함수 표기Unpacking the notation · function notation
X : Ω → ℝModule 2 · 06의 P : ℱ → [0,1]과 같은 표기야. "X는 Ω의 원소를 받아 실수를 뱉는다".
↦화살표 꼬리에 막대가 붙은 것. 원소 하나가 어디로 가는지를 쓸 때 써. →는 집합끼리, ↦는 원소끼리야.
X vs X(ω)앞은 함수 자체, 뒤는 그 함수가 뱉은 값. 관습상 둘 다 X로 쓰지만 머릿속에서는 구별해야 해.
대문자 / 소문자이 과목 내내 지켜지는 규칙이야. 대문자 X는 확률변수(함수), 소문자 x는 그것이 취할 수 있는 구체적인 값. 그래서 P(X ≤ x)가 말이 되고 P(x ≤ X)는 어색해.

"random variable"이라는 이름이 나쁘다는 걸 알아두면 편해. 무작위(random)하지도 않고 변수(variable)도 아니야. ω가 정해지면 X(ω)는 완전히 결정되는 결정론적 함수야. 무작위성은 전부 ω가 어떻게 뽑히느냐에 있어. 10번에서 이 관점이 핵심이 돼.

X : Ω → ℝThe same notation as P : ℱ → [0,1] in Module 2 · 06: "X takes an element of Ω and returns a real number".
↦The arrow with a bar on its tail. It says where a single element goes. Use → between sets and ↦ between elements.
X vs X(ω)The first is the function itself, the second is the value it returned. Convention writes both as X, but keep them apart mentally.
capital / lowercaseA convention held throughout the course. Capital X is the random variable (the function); lowercase x is a particular value it might take. That is why P(X ≤ x) reads naturally and P(x ≤ X) does not.

It helps to know the name is a bad one. A random variable is neither random nor a variable. Once ω is fixed, X(ω) is fully determined: it is a deterministic function. All the randomness sits in how ω gets drawn, and §10 turns that observation into the punchline of the module.

예제 2.1 · 슬라이드의 주사위 Example 2.1 · the die from the slides

주사위를 굴린다. Ω = {1,2,3,4,5,6}, X(ω) = ω. 이때 X는 무슨 함수야? 그리고 Y(ω) = (ω가 짝수면 1, 아니면 0)은?

Roll a die: Ω = {1,2,3,4,5,6} with X(ω) = ω. What function is X? And what about Y(ω) = 1 if ω is even, 0 otherwise?

풀이Solution

X는 항등함수야. 결과가 이미 숫자라서 그대로 쓰면 돼. ω = 4면 X = 4. 슬라이드가 첫 예제로 이걸 드는 이유는 가장 지루한 확률변수여서야. 결과와 값이 구별되지 않아 보이거든.

Y가 더 유익해. 값의 집합이 {0, 1}뿐이야. Y(2) = Y(4) = Y(6) = 1이라 결과 세 개가 같은 값으로 뭉쳐.

여기서 정보가 버려진다는 걸 봐. Y = 1이라는 걸 알아도 2였는지 4였는지 6이었는지는 몰라. 확률변수는 결과를 숫자로 요약하는 장치고, 요약에는 손실이 따라. 어떤 질문에 답하고 싶으냐에 따라 어떤 X를 쓸지가 정해져.

X is the identity function. The outcome is already a number, so nothing has to be done to it: ω = 4 gives X = 4. The slides lead with it precisely because it is the most boring random variable, the one where outcome and value look indistinguishable.

Y is the instructive one. Its value set is only {0, 1}, and Y(2) = Y(4) = Y(6) = 1, so three outcomes collapse onto one value.

Notice that information is thrown away. Knowing Y = 1 leaves you unable to say whether it was 2, 4, or 6. A random variable summarises outcomes as numbers, and summarising loses something. Which X you choose is decided by which question you want answered.

03

역상과 유도된 확률

Preimages and the induced measure

P는 Ω에서만 정의됐는데 어떻게 X의 확률을 묻나.

P lives on Ω, so how do we ask for a probability about X?

P(X ∈ A)라고 쓰고 싶은데, Module 2에서 못박았듯 P는 ℱ 위에서만 정의돼. A는 실수의 집합이지 Ω의 부분집합이 아니야. 그래서 슬라이드가 질문을 뒤집어. "어떤 ω가 A 안의 값을 만드나?"

We want to write P(X ∈ A), but as Module 2 insisted, P is only defined on ℱ, and A is a set of reals rather than a subset of Ω. So the slides turn the question around: which ω produce values inside A?

역상과 유도된 측도
X−1(A) = {ω ∈ Ω : X(ω) ∈ A}

이건 Ω의 부분집합이니까 P를 먹일 수 있어.

PX(A) = P(X(ω) ∈ A) = P(X−1(A))
Preimage and induced measure
X−1(A) = {ω ∈ Ω : X(ω) ∈ A}

That is a subset of Ω, so P can be applied to it.

PX(A) = P(X(ω) ∈ A) = P(X−1(A))
기호 뜯어보기 · X−1 은 역함수가 아니다Unpacking the notation · X−1 is not an inverse function
X−1(A)역상(preimage). A로 가는 ω를 전부 모은 집합이야. 결과가 집합이지 원소가 아니야.
역함수가 아닌 이유X가 일대일이 아니어도 X−1(A)는 항상 정의돼. 02번의 Y는 역함수가 없지만 Y−1({1}) = {2,4,6}은 멀쩡히 존재해.
괄호 안집합이 들어간다. X−1(3)이 아니라 X−1({3})이 엄밀한 표기야. 실제로는 줄여 쓰는 일이 많아.
PX아래첨자 X는 "X가 유도한"이라는 뜻. P는 Ω 위의 측도고 PX는 ℝ 위의 측도라 서로 다른 것이야. 아래첨자가 그 구별의 전부야.

P(X ≤ x)도 사실 줄임말이야. 풀어 쓰면 P({ω : X(ω) ≤ x})야. 이 과목 내내 이렇게 줄여 쓰니까 중괄호가 생략됐다는 걸 알고 읽어야 해.

X−1(A)The preimage: the set of all ω that map into A. It returns a set, not an element.
why it is not an inverseX−1(A) is defined whether or not X is one-to-one. The Y from §02 has no inverse function, yet Y−1({1}) = {2,4,6} exists perfectly well.
what goes in the bracketsA set. Strictly it is X−1({3}) rather than X−1(3), though the short form is common in practice.
PXThe subscript reads "induced by X". P is a measure on Ω and PX a measure on ℝ, so they are different objects, and the subscript is the only thing marking that.

P(X ≤ x) is itself an abbreviation, for P({ω : X(ω) ≤ x}). The short form is used throughout the course, so read it knowing the braces have been dropped.

왜 Module 2의 σ-algebra가 여기서 값을 하는지 보여. P(X−1(A))를 쓰려면 X−1(A)가 ℱ에 들어 있어야 해. 아무 함수나 되는 게 아니고, 모든 A에 대해 역상이 사건이 되는 함수만 확률변수라고 부를 자격이 있어. 이 조건을 가측(measurable)이라고 해.

슬라이드는 이 조건을 명시하지 않고 넘어가. 이 과목에서 다루는 함수는 다 가측이라 실제로 문제가 안 생기거든. 다만 Module 2의 Borel σ-algebra가 여기 쓰이려고 있었던 거야. A가 구간이면 X−1(A)가 사건이라는 걸 보장하는 게 그거야.
This is where Module 2's σ-algebra earns its keep. Writing P(X−1(A)) requires X−1(A) to be in ℱ. Not every function qualifies: only those whose preimages are events for every A deserve the name random variable. That condition is called being measurable.

The slides pass over it, and reasonably so, since everything in this course is measurable and nothing goes wrong. Still, the Borel σ-algebra from Module 2 exists for exactly this moment: it is what guarantees that X−1(A) is an event whenever A is an interval.
04

CDF

이산이든 연속이든 항상 존재하는 유일한 기술 방법.

The one description that always exists, discrete or continuous.

누적분포함수 (CDF)
FX(x) = P(X ≤ x) = PX((−∞, x])

슬라이드가 굵게 강조하는 것: PMF(이산)나 PDF(연속)와 달리 CDF는 연속형과 이산형 둘 다에 대해 정의된다. 그래서 정의가 하나면 되는 유일한 도구야.

성질 세 가지: FX(−∞) = 0, FX(+∞) = 1, 그리고 FX는 비감소이고 우연속(right-continuous)이다.

Cumulative distribution function
FX(x) = P(X ≤ x) = PX((−∞, x])

The point the slides put in bold: unlike a PMF (discrete) or PDF (continuous), the CDF is defined for both kinds of random variable. It is the only tool here that needs a single definition.

Three properties: FX(−∞) = 0, FX(+∞) = 1, and FX is nondecreasing and right-continuous.

CDF로 계산하기
P(X > x) = 1 − FX(x)     P(a < X ≤ b) = FX(b) − FX(a)

첫 줄은 Module 2의 여집합 규칙이고 둘째 줄은 (−∞,b] = (−∞,a] ∪ (a,b]라는 서로소 분해야. 새로운 게 하나도 없어. 공리에서 나온 것들을 CDF 언어로 옮긴 것뿐이야.

Computing with the CDF
P(X > x) = 1 − FX(x)     P(a < X ≤ b) = FX(b) − FX(a)

The first is Module 2's complement rule; the second is the disjoint decomposition (−∞,b] = (−∞,a] ∪ (a,b]. Nothing new is happening: these are consequences of the axioms, restated in CDF language.

함정

부등호의 방향과 등호가 전부 의미를 갖는다

FX는 ≤로 정의돼. 그래서 P(a < X ≤ b) = F(b) − F(a)는 왼쪽 끝이 열리고 오른쪽이 닫힌 구간이야. P(a ≤ X ≤ b)를 원하면 P(X=a)를 따로 더해야 해.

연속형이면 P(X=a) = 0이라 이 구별이 사라져. 그래서 연속 문제만 풀다 보면 습관이 안 들고, 이산 문제에서 그대로 틀려. HW3 P1이 이산이야.

우연속인 것은 정의의 ≤ 때문이다

이산 CDF는 계단 모양인데, 각 계단에서 위쪽 값을 취해. X가 주사위면 F(3) = 3/6이지 2/6이 아니야. X ≤ 3에 3이 포함되니까. 왼쪽에서 접근하면 2/6이라 좌연속은 아니야.

그래서 점프의 크기가 곧 그 점의 확률이야. P(X=a) = F(a) − F(a−). 슬라이드 손글씨가 이걸 유도해.

FX가 줄어드는 일은 없다

비감소는 단조성에서 바로 나와. a ≤ b면 (−∞,a] ⊆ (−∞,b]니까. 답이 줄어드는 CDF가 나왔다면 계산이 틀린 거야. HW3 P4처럼 CDF를 직접 구하는 문제에서 검산으로 쓸 수 있어.

Traps

Every inequality sign and equals sign carries meaning

FX is defined with ≤, so P(a < X ≤ b) = F(b) − F(a) covers an interval that is open on the left and closed on the right. For P(a ≤ X ≤ b) you must add P(X=a) back in.

In the continuous case P(X=a) = 0 and the distinction evaporates. Practise only on continuous problems and the habit never forms, then it costs you on a discrete one. HW3 P1 is discrete.

Right-continuity comes from the ≤ in the definition

A discrete CDF is a staircase that takes the upper value at each step. For a die, F(3) = 3/6, not 2/6, because X ≤ 3 includes 3. Approach from the left and you get 2/6, so it is not left-continuous.

Which makes the height of each jump the probability of that point: P(X=a) = F(a) − F(a−). The handwriting on the slides derives exactly this.

A CDF never decreases

Nondecreasing follows straight from monotonicity, since a ≤ b gives (−∞,a] ⊆ (−∞,b]. If your CDF goes down somewhere, the algebra is wrong. Use it as a check on problems like HW3 P4 where you derive a CDF by hand.

Module 1의 가산/비가산 구분이 여기서 값을 한다. Module 1 · 06에서 "왜 셀 수 있는지가 중요한가"를 다뤘는데, 답이 이거야. 가산이면 하나씩 확률을 붙여서 더할 수 있고(PMF), 비가산이면 그게 불가능해서 적분으로 가야 해(PDF).

Module 2 · 06번 함정에서 든 얘기가 정확히 이거였어. [0,1]에서 각 점의 확률이 0인데 비가산 개를 모으면 1이 되어야 한다는 모순. 그래서 연속형은 점이 아니라 구간에 확률을 붙인다.
Module 1's countable/uncountable distinction pays off here. Module 1 · 06 asked why countability matters, and this is the answer. Countable means you can attach a probability to each value and add them up (PMF); uncountable means you cannot, and you have to integrate instead (PDF).

It is the same point as the trap in Module 2 · 06: on [0,1] each single point has probability 0, yet uncountably many of them would have to sum to 1. So in the continuous case probability attaches to intervals, not points.

PDF

연속형: 확률이 아니라 밀도다. 적분해야 확률이 된다.

함정

fX(x)는 확률이 아니다. 1을 넘어도 된다

X ~ U[0, 0.5]면 fX(x) = 2야. 확률이 2일 수는 없지만 밀도는 2일 수 있어. 밀도 × 폭이 확률이니까, 폭이 0.5면 2 × 0.5 = 1로 맞아떨어져. PMF와 PDF의 결정적 차이가 이거야. PMF 값은 확률이라 ≤ 1이어야 하지만 PDF 값은 아무 제약이 없어(음수만 아니면 돼).

P(X = x) = 0이지 불가능한 게 아니다

슬라이드가 이걸 Important로 따로 강조해. "This does not mean that the outcome X = x is impossible." [0,1]에서 균등하게 뽑으면 어떤 값이든 나오긴 나와. 그런데 그 특정 값이 나올 확률은 0이야.

Module 2에서 "∅이면 확률 0이지만 확률 0이라고 ∅은 아니다"라고 했던 게 여기서 실물로 나타나. 확률 0인 사건이 실제로 일어나는 게 연속형에서는 매일 일어나는 일이야.

연속형에서는 등호가 의미를 잃는다

P(a < X < b) = P(a ≤ X ≤ b)야. 끝점의 확률이 0이니까. 편해 보이지만 이산형에서 같은 습관을 쓰면 틀려. 문제를 받으면 이산인지 연속인지 먼저 확인해.

PDF는 미분 가능할 때만 CDF에서 얻어진다

슬라이드가 "If FX is differentiable"이라는 단서를 달아. 균등분포의 CDF는 x=0과 x=1에서 꺾여서 미분이 안 돼. 그 두 점에서 PDF 값은 정의하기 나름이고, 어떻게 정하든 적분값이 안 바뀌어서 상관없어. 그래서 교과서마다 f(1) = 1이라 쓰기도 하고 0이라 쓰기도 해.

Traps

fX(x) is not a probability and may exceed 1

For X ~ U[0, 0.5], fX(x) = 2. A probability of 2 is impossible, but a density of 2 is fine: density times width is probability, and 2 × 0.5 = 1 works out. This is the decisive difference from a PMF, whose values are probabilities and must be ≤ 1. A PDF has no upper constraint at all, only non-negativity.

P(X = x) = 0 does not mean impossible

The slides flag this as Important: "This does not mean that the outcome X = x is impossible." Draw uniformly from [0,1] and some value does come out, yet the probability of that particular value was 0.

Module 2's line that ∅ has probability 0 but probability 0 does not imply ∅ becomes concrete here. In the continuous world, probability-zero events happen every single time.

The equals sign stops mattering in the continuous case

P(a < X < b) = P(a ≤ X ≤ b), since the endpoints carry no probability. Convenient, but carrying that habit into a discrete problem gets it wrong. Check which kind you have before you start.

Differentiating the CDF only works where it is differentiable

The slides hedge with "if FX is differentiable". The uniform CDF has corners at x=0 and x=1 where no derivative exists. At those two points the density is yours to define, and any choice integrates to the same thing, which is why textbooks variously write f(1) = 1 or 0.

Binomial과 Geometric을 헷갈리지 마. 둘 다 "p로 성공하는 시행 반복"인데 세는 대상이 달라. Binomial은 횟수를 고정하고 성공 개수를 세고, Geometric은 성공 하나를 고정하고 걸린 시도 수를 세. 그래서 Binomial의 값은 0…n으로 유한하고 Geometric은 1, 2, 3, …으로 가산 무한이야.

Keep Binomial and Geometric apart. Both describe repeated trials with success probability p, but they count different things. Binomial fixes the number of trials and counts successes; Geometric fixes one success and counts the trials it took. So Binomial takes finitely many values 0…n while Geometric ranges over 1, 2, 3, …, countably infinite.

함정

Geometric의 정의가 책마다 다르다

슬라이드는 pX(k) = (1−p)k−1p, k = 1, 2, …로 시도 횟수를 세. 그런데 실패 횟수를 세는 정의도 흔해. 그러면 (1−p)kp, k = 0, 1, …가 돼.

시작이 1이냐 0이냐로 구별해. 이 과목은 슬라이드 정의를 따르고, HW3 Problem 2가 "number of transmission attempts needed until the first success"라고 해서 시도 횟수 쪽이야. 05번에서 슬라이드가 "첫 성공까지의 실패 횟수"를 가산 무한의 예로 든 것과 대비돼. 문제를 읽을 때 어느 쪽인지 확인해.

Poisson의 λ는 확률이 아니다

λ는 평균 개수라서 3.7일 수도 20일 수도 있어. 다른 분포의 p가 [0,1]에 갇혀 있는 것과 달라. 슬라이드 손글씨가 Poisson을 n → ∞, p → 0, np = λ 고정인 Binomial의 극한으로 유도해. 그래서 λ가 np 자리에 있는 거야.

지원 집합(support)을 빠뜨리면 안 된다

PMF를 쓸 때 k = 1, 2, … 같은 범위를 반드시 같이 써. 범위 없이 식만 쓰면 k = 0이나 음수에서 값이 뭔지 알 수 없어. 슬라이드가 매번 "0, otherwise"를 붙이는 게 그래서야. HW3 P1의 c를 구할 때도 어느 범위에서 더할지가 답을 정해.

Traps

The Geometric distribution is defined two different ways

The slides use pX(k) = (1−p)k−1p, k = 1, 2, …, counting attempts. Counting failures is equally common and gives (1−p)kp, k = 0, 1, … instead.

Tell them apart by whether the support starts at 1 or 0. This course follows the slides, and HW3 Problem 2 says "number of transmission attempts needed until the first success", so it is the attempts version. Contrast that with §05, where the slides cite "failures before the first success" as their countably-infinite example. Read each problem for which one it wants.

The Poisson λ is not a probability

λ is an average count, so it can be 3.7 or 20, unlike the p of the other distributions which is confined to [0,1]. The handwriting on the slides derives Poisson as a Binomial limit with n → ∞, p → 0 and np = λ held fixed. That is why λ sits where np used to.

Never omit the support

Always write the range, such as k = 1, 2, …, alongside the formula. Without it there is no saying what happens at k = 0 or at negative values. It is why the slides append "0, otherwise" every single time. In HW3 P1 the range you sum over is what determines c.

Binomial and Geometric in §08 stand in the same relation. "How many in a fixed window" gives you one distribution, "how long until the next one" gives you another, discrete or continuous. Seeing that pairing means not memorising five separate things.
함정

Gaussian의 두 번째 모수는 σ2이지 σ가 아니다

N(0, 4)는 표준편차가 4가 아니라 2야. 분산이 4니까. 반면 Rayleigh는 σ로 모수화돼 있어(Rayleigh(σ)). 슬라이드가 그렇게 써. 같은 글자가 두 분포에서 다른 것을 뜻해.

Exponential과 Rayleigh는 x ≥ 0에서만 산다

정의역 제한을 빼먹고 적분하면 1이 안 나와. 지원 집합은 PDF의 일부야. 물리적으로도 당연해. 시간 간격과 신호 크기는 음수가 될 수 없거든. Gaussian만 ℝ 전체에 퍼져 있어서, 전력이나 시간을 Gaussian으로 모델링하면 음수가 나온다는 게 실제 문제가 돼.

Lognormal은 X가 정규가 아니라 ln X가 정규다

이름이 헷갈리게 돼 있어. X 자체는 정규분포가 아니야. 로그를 취해야 정규가 돼. 그래서 x > 0에서만 정의되고(로그를 취해야 하니까) PDF에 1/x가 붙어. 무선에서 섀도잉을 dB로 재면 정규분포처럼 보이는데, dB가 곧 로그라서 그래.

Traps

The Gaussian's second parameter is σ2, not σ

N(0, 4) has standard deviation 2, not 4, because 4 is the variance. Meanwhile Rayleigh is parameterised by σ itself, written Rayleigh(σ) on the slides. The same letter means different things in the two distributions.

Exponential and Rayleigh live only on x ≥ 0

Integrate without the domain restriction and you will not get 1. The support is part of the PDF. Physically it has to be: an inter-arrival time and a signal magnitude cannot go negative. The Gaussian is the one spread over all of ℝ, which is why modelling a power or a duration as Gaussian eventually produces negative values and causes real trouble.

Lognormal means ln X is normal, not X

The name invites the wrong reading. X itself is not Gaussian; its logarithm is. Hence it is defined only for x > 0, since you have to take a log, and hence the 1/x factor in the density. Shadow fading measured in dB looks Gaussian precisely because dB is a logarithm.

Inverse transform sampling

이 모듈의 결론. 균등 난수 하나로 아무 분포나 만든다.

The module's payoff: one uniform random number becomes any distribution you like.

슬라이드가 "A Final Remark"로 시작해서 끝까지 가는 대목이야. 확률 공간을 ([0,1], ℬ([0,1]), 균등) 하나로 고정해놓고, 원하는 CDF FX를 갖는 확률변수를 만들어내.

This is the stretch the slides open with "A Final Remark" and carry to the end. Fix a single probability space, ([0,1], ℬ([0,1]), uniform), and construct a random variable with whatever CDF FX you want.

구성과 증명
X(u) = FX−1(u),    u ∈ [0,1]

이게 정말 FX를 CDF로 갖는지 확인하는 게 두 줄이야.

P(X ≤ x) = P(FX−1(u) ≤ x) = P(u ≤ FX(x)) = FX(x)
The construction and its proof
X(u) = FX−1(u),    u ∈ [0,1]

Checking that this really has FX as its CDF takes two lines.

P(X ≤ x) = P(FX−1(u) ≤ x) = P(u ≤ FX(x)) = FX(x)
마지막 등호가 이 증명의 전부야. u가 [0,1] 위에서 균등이니까 P(u ≤ t) = t야. 균등분포의 CDF가 항등함수라는 사실이 여기서 값을 해. t 자리에 FX(x)를 넣으면 바로 FX(x)가 나와.

가운데 등호는 FX가 비감소라서 부등호를 유지한 채 양변에 FX를 씌울 수 있다는 것에 기대. 04번의 성질이 여기서 쓰인다.
The last equality is the whole proof. Because u is uniform on [0,1], P(u ≤ t) = t. The uniform CDF being the identity function is what does the work: substitute FX(x) for t and out comes FX(x).

The middle equality leans on FX being nondecreasing, which is what lets you apply it to both sides without flipping the inequality. That property from §04 is being cashed in here.

The interpretation the slides close on is the most important sentence in the module. Fix one probability space, the uniform measure on [0,1], and apply different deterministic maps to the same u to construct most of the random variables engineering needs.

The remark in §02 that a random variable is really a deterministic function, with all the randomness sitting in ω, arrives at its conclusion here. One source of randomness is enough. Everything else is transformation.
함정

F−1이 진짜 역함수가 아닐 수 있다

Bernoulli의 CDF는 계단이라 대부분의 값을 건너뛰어. F(x) = 0.5인 x가 없을 수 있어. 그래서 엄밀히는 일반화 역함수 F−1(u) = inf{x : F(x) ≥ u}를 써.

슬라이드의 Bernoulli 결과가 정확히 이거야. u ≤ 1−p면 0, 아니면 1. 계단을 왼쪽에서 오른쪽으로 훑다가 처음으로 u 이상이 되는 지점을 고르는 거야. 03번의 X−1도 역함수가 아니었지. 이 과목에서 −1은 대체로 역함수가 아니야.

1 − u와 u를 바꿔 써도 된다

Exponential의 공식이 −(1/λ)ln(1 − u)인데, u가 균등이면 1 − u도 균등이라 −(1/λ)ln u로 써도 같은 분포가 나와. 구현에서는 후자를 더 많이 써. 다만 u = 0이 나오면 ln 0이라 발산하니 (0,1]에서 뽑아야 해.

Gaussian은 이 방법으로 못 만든다

정규분포의 CDF에는 닫힌 형태의 역함수가 없어. 그래서 실제 라이브러리는 Box-Muller 같은 다른 방법을 써. 역변환은 원리를 보여주는 데 완벽하지만 모든 분포에 실용적이지는 않아. 슬라이드가 예제로 균등·지수·Bernoulli 셋만 든 것도 그 셋이 역함수가 깔끔해서야.

Traps

F−1 may not be a genuine inverse

The Bernoulli CDF is a staircase and skips most values: there may be no x at all with F(x) = 0.5. Strictly one uses the generalised inverse F−1(u) = inf{x : F(x) ≥ u}.

That is exactly what the slides' Bernoulli result encodes: 0 when u ≤ 1−p and 1 otherwise, which is sweeping the staircase left to right and taking the first point where it reaches u. The X−1 in §03 was not an inverse either. In this course a superscript −1 usually is not one.

You can swap 1 − u for u

The Exponential formula is −(1/λ)ln(1 − u), but if u is uniform so is 1 − u, so −(1/λ)ln u gives the same distribution. Implementations usually prefer the latter, drawing from (0,1] so that ln 0 never comes up.

The Gaussian cannot be built this way

The normal CDF has no closed-form inverse, which is why real libraries reach for Box-Muller or similar instead. Inverse transform is perfect for showing the principle and not universally practical. The slides pick uniform, exponential and Bernoulli as examples precisely because those three invert cleanly.

단순한 무작위성 → 변환 → 복잡한 분포

생성 모델은 대개 가우시안 잡음 같은 단순한 입력에서 출발해서 그것을 변환해 훨씬 복잡한 분포의 표본을 만들어. 정규화 흐름(normalizing flows), 확산 모델(diffusion), VAE, GAN이 전부 이 구조야. 차이는 변환을 손으로 유도하느냐 데이터로 학습하느냐뿐이야.
The slide compresses it to one line.

simple source of randomness → transformation → complex distribution

Generative models start from a simple input such as Gaussian noise and transform it into samples from something far more complicated. Normalizing flows, diffusion models, VAEs and GANs all share that shape. The only difference is whether the transformation is derived by hand or learned from data.

Things to look for. ① Sweep u evenly and the exponential's x does not move evenly. Where the CDF is steep, near 0, a change in u barely moves x; out in the flat tail it jumps a long way. That is why the samples pile up near zero. ② Switch to Bernoulli and the staircase CDF lets x take only 0 and 1. ③ Draw 200 and the histogram grows into the shape of the PDF.
