x ∈ Ω를 하나 잡고 x ∈ LHS ⟺ x ∈ RHS를 보인다. 한 방향씩 쓰거나, 모든 단계가 동치면 한 줄기로 쓰고 "각 단계가 ⟺"라고 밝혀도 돼.

First move

Suggested order: (c) → (a) → (b). Part (c) is shortest, so it gets your hand used to the format, and (b) has the most pieces so it is easier last.

빠뜨리기 쉬운 것

벤 다이어그램은 증명이 아니다

문제지에 "use an element-wise argument"라고 명시돼 있어. 그림만 그려서 내면 요구를 안 지킨 거야. 그림은 검산에 쓰고, 답안은 원소를 잡고 시작해.

⟸ 방향을 빼먹는 것

집합이 같다는 건 양쪽 포함을 다 보여야 해. 한 방향만 쓰면 ⊆만 증명한 거야. 각 단계가 동치라면 그렇게 적어야 한 방향으로 끝낼 수 있어.

Easy to miss

A Venn diagram is not a proof

The assignment explicitly says "use an element-wise argument". Handing in a drawing does not meet the requirement. Use pictures to check, then write the proof starting from an element.

Dropping the ⟸ direction

Set equality needs both inclusions. One direction alone proves only ⊆. If every step really is an equivalence, you have to say so to be allowed to finish in one direction.

빠뜨리기 쉬운 것

(d)에서 조건 ①만 확인하고 끝내는 것

분할은 서로소와 덮음 둘 다야. 그리고 서로소는 모든 쌍을 봐야 해. 조각이 3개면 확인할 쌍이 3개야. 왜 전체 교집합만 보면 안 되는지는 Module 1 · 09번 함정에 반례로 나와 있어.

(e)는 계산이 아니라 서술이다

"Explain in words"야. 채점자가 보고 싶은 건 "겹치지 않으니 두 번 세지 않고, 다 덮으니 빠뜨리지 않는다"는 두 문장이야. 이게 Module 3의 전확률 법칙으로 이어진다는 걸 덧붙이면 더 좋고.

Easy to miss

Checking only condition ① in part (d)

A partition needs disjointness and covering, both. And disjointness means every pair: three pieces gives three pairs. Why the total intersection is not the right test is shown with a counterexample in Module 1 · the §09 traps.

Part (e) is prose, not arithmetic

It says "Explain in words". What is wanted is two sentences: nothing overlaps so nothing is counted twice, and everything is covered so nothing is missed. Mentioning that this becomes the law of total probability in Module 3 is a bonus.

"서로소 조각으로 쪼개고 공리 ③을 적용한다." 이 한 문장이 네 증명 전부야. 공리 ③은 서로소일 때만 쓸 수 있으니, 창의성은 전부 어떻게 쪼갤까에 들어가.

"Split into disjoint pieces, then apply axiom ③." That one sentence is all four proofs. Axiom ③ only works on disjoint sets, so every bit of creativity goes into how you split.

  • (b) Ω = A ∪ Ac, the {A, Ac} partition from Module 1
  • (c) B = A ∪ (B\A)

채점 포인트

공식을 인용하면 점수가 안 나온다

문제지에 "do not simply quote the formulas. Explain how they follow from the probability axioms and appropriate set decompositions"라고 적혀 있어. "적절한 집합 분해"를 명시적으로 쓰는 게 채점 대상이야. 각 줄에서 어느 공리를 썼는지 괄호로 달아두면 확실해.

(a)에서 "0이니까 0"이라고 쓰는 것

P(∅) = p로 두고 p = p + p + ⋯가 되니 p > 0이면 발산한다는 논증이 있어야 해. 결론만 쓰면 유도가 아니야.

Where the marks are

Quoting the formulas earns nothing

The assignment says "do not simply quote the formulas. Explain how they follow from the probability axioms and appropriate set decompositions". Naming the decomposition explicitly is the thing being marked. Tagging each line with the axiom you used makes it unambiguous.

Writing "it is 0 because it is 0" in part (a)

You need the argument: set P(∅) = p, note that ③ forces p = p + p + ⋯, and that any p > 0 diverges. A bare conclusion is not a derivation.

First move

Write the geometric series ∑n≥1 rn = r/(1−r) at the top of the page before anything else. Parts (a), (c) and (d) are all variations on it: (c) uses r = 1/4, (d) is a tail sum.

Check (d) against A1 = Ω, which must give P(A1) = 1. If it does not, an exponent is off.

빠뜨리기 쉬운 것

(f)가 이 문제의 목적이다

(a)–(e)는 준비 운동이고, (f)에서 lim P(An)와 P(⋂An)가 같다는 걸 확인하는 게 핵심이야. 두 값을 나란히 쓰고 "따라서 연속성 정리와 일치한다"라고 맺어야 문제가 끝나.

(e)에서 "0으로 수렴하니까 ∅"이라고 쓰는 것

방향이 반대야. ⋂An = ∅은 집합 계산으로 보여야 해. 어떤 k를 잡아도 k ∉ Ak+1이라는 논증이야. 확률은 그다음이야.

Easy to miss

Part (f) is the point of the problem

Parts (a) through (e) are the warm-up. The core is confirming in (f) that lim P(An) and P(⋂An) agree. Write the two values side by side and close with "consistent with continuity of probability".

Arguing in (e) that it is ∅ because the limit is 0

That runs backwards. ⋂An = ∅ has to be shown as a set computation: whatever k you pick, k ∉ Ak+1. The probability comes afterwards.
